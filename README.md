# ASX AI Structural Comparison

IMPACT × FAVES dual-axis framework analysis of AI executive exposure across ASX-listed companies, constructed for maximum contrast across the Bits / Atoms / Institutional / Cognitive constraint surface.

**Author:** Walter Adamson — OutcomesNow

## File Relationship

The files form a 4-layer analytical workflow:

### Layer 1 — Planning (estimated figures, 6 companies)

- `asx_ai_exposure_portfolio_contrast_map.html` — Standalone publishable contrast map with design rationale and recommended reading order. Uses estimated figures for all 6 planned companies including Xero (XRO). Originally derived from a ChatGPT canvas artifact.

### Layer 2 — Individual Company Dashboards (actual scored data)

Each dashboard contains full IMPACT × FAVES task-level scoring for one company's executive team:

- `genusplus_gnp_ai_job_exposure_dashboard.html` — GenusPlus Group (ASX: GNP) — Atoms constraint
- `wisetech_wtc_ai_job_exposure_dashboard.html` — WiseTech Global (ASX: WTC) — Bits constraint
- `kellypartners_kpg_ai_job_exposure_dashboard.html` — Kelly Partners Group (ASX: KPG) — Institutional constraint
- `csl_csl_ai_job_exposure_dashboard.html` — CSL Limited (ASX: CSL) — Atoms + Institutional constraint
- `seek_sek_ai_job_exposure_dashboard.html` — SEEK Limited (ASX: SEK) — Cognitive constraint

**Note:** Xero (XRO, Bits + Cognitive) was in the original 6-company plan but was not analysed.

### Layer 2b — Supplementary

- `genusplus_gnp_ai_instinct_assessment.html` — Separate earlier-format assessment of GenusPlus (different analytical lens from the Job Exposure Dashboard)

### Layer 3 — Portfolio Synthesis (final capstone)

- `impact_x_faves_5company_asx_portfolio_synthesis.html` — Cross-company comparison of all 5 completed analyses. 599 tasks, 51 executives, 5 constraint types. Contains Chart.js visualisations, constraint ontology, CFO signal analysis, board questions, and methodology.

## Framework

- **IMPACT** (business case): Investment, Multiplicity, Pain, Accrued value, Cost, Trend
- **FAVES** (technical feasibility): Fidelity, Autonomy, Volatility, Entanglement, Step decomposability
- Calibrated against O*NET-SOC taxonomy, Anthropic Economic Index (Jan 2026), METR evaluations, frontier model benchmarks (Mar 2026)
